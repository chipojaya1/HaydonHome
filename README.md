# HaydonHome

The public-facing website for the proposed HaydonHome guesthouse in Zimbabwe.

**Website:** https://chipojaya1.github.io/HaydonHome/

This repository contains only visitor-facing content: the guesthouse vision, proposed development journey, public progress snapshot, and milestones. Dates are planning targets, not confirmed construction completion dates.

## Website files
- `index.html` — public homepage
- `styles.css` — styling and responsive layout
- `script.js` — lightweight client-side behavior
- `.github/workflows/pages.yml` — Pages deployment workflow

## Publishing
In **Settings → Pages**, set **Source → GitHub Actions**. The workflow publishes this repository's static files. Check **Actions** for the latest result.

## Private project records
All private budgets, decisions, approvals, project tasks, and internal dashboard files remain in the separate private **Haydonproject** repository. Do not copy private files into this public repository.
